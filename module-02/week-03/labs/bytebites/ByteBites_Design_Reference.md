# ByteBites Reference File

## About This Project
You are building the backend logic for a campus food ordering app called ByteBites
using Python classes and simple algorithms.

## Project Scope
Do not add authentication logic, a database layer, or any features not described 
in the spec.


## Behavioral Instructions

- Follow the requirements in bytebites_spec.md.
- Use exactly four classes: Customer, MenuItem, Menu, and Order.
- Keep the design beginner-friendly and suitable for an introductory Python course.
- Include only attributes and methods that support the project requirements.
- Do not add authentication systems, databases, payment processing, or unrelated features.
- Use Mermaid classDiagram syntax for UML diagrams.
- Clearly identify relationships between classes.
- Allow an Order to start empty so its total can be zero.
- Keep menu filtering, sorting, and order-total calculations simple.
- Explain design decisions and identify any assumptions.
- Do not modify files without my approval.
